# ⚡ Quick Run - Local Server Scripts

## 🎯 Just Want to Run the Server?

### **Double-Click This:**
```
run_server.bat
```

That's it! Your server will start on: **http://127.0.0.1:8000**

---

## 📋 Available Scripts

| Script | Command | Use When |
|--------|---------|----------|
| **run_server.bat** | `.\run_server.bat` | Normal development |
| **run_server_with_migrate.bat** | `.\run_server_with_migrate.bat` | After code/model changes |
| **dev_setup.bat** | `.\dev_setup.bat` | First time setup |
| **run_server.ps1** | `.\run_server.ps1` | PowerShell preference |

---

## 🚀 Step-by-Step

### First Time
1. Double-click: `dev_setup.bat`
2. Wait for completion
3. Double-click: `run_server.bat`

### Every Other Time
- Double-click: `run_server.bat`

### After Git Pull or Model Changes
- Double-click: `run_server_with_migrate.bat`

---

## 🌐 Once Running

| Page | URL |
|------|-----|
| Website | http://127.0.0.1:8000 |
| Admin Panel | http://127.0.0.1:8000/admin |
| Contact | http://127.0.0.1:8000/contact |
| Register | http://127.0.0.1:8000/register |

---

## ⏹️ Stop Server

Press: **Ctrl + C** in the terminal
